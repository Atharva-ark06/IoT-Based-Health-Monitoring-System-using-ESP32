# Threat Model Refresh Triggers

Refresh the threat model when:

- A new API route, role, device type, or external integration is added.
- Authentication, key provisioning, session handling, or authorization changes.
- Data categories, retention, export, or dashboard visibility change.
- Deployment moves from local/loopback to a network-accessible environment.
- A vulnerability or incident reveals a missing assumption.
- The database schema or backup strategy changes.

Revisit assets, trust boundaries, attacker capabilities, abuse cases, mitigations, and residual risks.
