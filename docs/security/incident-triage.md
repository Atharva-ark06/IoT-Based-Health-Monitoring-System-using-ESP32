# Incident Triage Runbook

1. Capture the report source, first observed time, affected route/device, and release revision.
2. Preserve available metadata and logs using restricted access.
3. Determine whether secrets, health-related data, or data integrity may be affected.
4. Avoid sharing raw records or credentials in issue comments.
5. Assign severity and incident owner.
6. Decide containment actions and record the rationale.
7. Notify the designated security/privacy owner when sensitive data may be involved.
8. Maintain a timeline of evidence and actions.

Do not run intrusive tests against third-party systems while investigating.
