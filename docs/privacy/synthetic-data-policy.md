# Synthetic Data Policy

Automated tests, screenshots, demos, and presentations should use synthetic readings only.

- Label generated data as synthetic in the UI or accompanying documentation.
- Do not use a real person's readings as test fixtures.
- Use deterministic fixtures for repeatable assertions and randomized fixtures only where randomness is part of the test.
- Avoid real names, phone numbers, addresses, or realistic identity combinations.
- Keep any sample secrets obviously fake and non-reusable.
- Do not present synthetic values as clinically meaningful measurements.
