# Privacy Impact Review

Run this review before introducing a new data category, dashboard feature, integration, or external service.

1. Identify the data fields and whose data they may represent.
2. State the purpose and why each field is necessary.
3. Map storage, transit, logs, backups, and access paths.
4. Identify who can view, export, modify, or delete the data.
5. Define retention, deletion, and backup expiry behavior.
6. Assess re-identification and unintended disclosure risks.
7. Record mitigations, owner, and approval decision.

This is a review aid, not a claim that a formal legal privacy assessment has already been completed.
