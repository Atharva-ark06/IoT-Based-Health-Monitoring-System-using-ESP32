# Release Checklist

- [ ] PR targets `master` and review is complete.
- [ ] CI passes on the exact candidate commit.
- [ ] Dependency and static-analysis checks are reviewed.
- [ ] Configuration changes and secret requirements are documented.
- [ ] Backup exists before any destructive maintenance or schema change.
- [ ] Deployment and rollback instructions are available.
- [ ] Privacy and security impacts are reviewed.
- [ ] Synthetic smoke tests pass.
- [ ] Hardware claims are limited to tests actually performed.
- [ ] Release owner records revision, date, and outcome.
